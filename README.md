# Healthcare Analytics – Doctor Visits

## Project Overview

This project analyzes healthcare data to explore doctor visits, patient demographics, illness levels, and chronic conditions.

## Objectives

* Analyze doctor visit patterns.
* Explore patient age and gender.
* Compare visits across illness levels.
* Examine chronic conditions and doctor visits.
* Visualize healthcare data using graphs.
