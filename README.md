# Healthcare Analytics – Doctor Visits

## Project Overview

This project analyzes healthcare data to explore doctor visits, patient demographics, illness levels, and chronic conditions.

## Objectives

* Analyze doctor visit patterns.
* Explore patient age and gender.
* Compare visits across illness levels.
* Examine chronic conditions and doctor visits.
* Visualize healthcare data using graphs.

## Tools Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis

* Data inspection
* Univariate analysis
* Bivariate analysis
* Multivariate analysis
* Summary statistics
* Data visualization

## Project Files

* Healthcare Analytics notebook (`.ipynb`)

## Conclusion

The project uses data analysis and visualization to explore patterns in doctor visits and patient characteristics.
