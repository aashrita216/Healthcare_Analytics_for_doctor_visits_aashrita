# Healthcare Analytics – Doctor Visits

## Project Overview

This project analyzes healthcare data to understand patient doctor visits, demographic patterns, illness levels, and chronic conditions.

## Objectives

* Analyze the distribution of doctor visits.
* Explore patient age and gender.
* Compare doctor visits across gender and illness levels.
* Examine patterns related to chronic conditions.
* Visualize relationships in the healthcare dataset.

## Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis Performed

* Data inspection and cleaning checks
* Univariate analysis
* Bivariate analysis
* Multivariate analysis
* Summary statistics
* Data visualization

## Dataset

The dataset contains 5,190 patient records and 13 columns.

## Project Files

* `Healthcare_Analytics.ipynb` – Notebook containing the analysis and visualizations.
* `healthcare.csv` – Dataset, if permitted to share.

## Conclusion

This project uses data analysis and visualization to explore patterns in doctor visits and patient characteristics. The findings can help identify patterns for further investigation in healthcare management.
